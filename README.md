## ⚜️ About The Project

**SILLAGE** (pronounced *see-yahzh*) refers to the trail of scent left behind by a perfume. This project is a highly curated, ultra-luxury archive of elite fragrances. Originally a simple HTML/JS catalog, it has been completely re-architected into a state-of-the-art Single Page Application (SPA) designed to provide a premium, dynamic, and immersive user experience.

### ✨ Key Features
- **Elite Performance**: Rebuilt from the ground up using **React** and **Vite** for lightning-fast module replacement and optimized production builds.
- **Cinematic Animations**: Powered by **Framer Motion**, the application features staggering waterfall load effects, 3D tilt interactions on cards, and buttery-smooth page transitions.
- **Dynamic Theming**: Custom-built CSS architecture utilizing variables to support seamless switching between an elegant Dark Mode (Gold & Obsidian) and a pristine Light Mode (Marble & Gold).
- **Advanced Filtering Engine**: Instantly filter through dozens of niche houses (Creed, Tom Ford, Xerjoff, Nishane, etc.) and search by specific fragrance names with zero latency.
- **Data-Driven Architecture**: Fragrance data (including specific accords, longevity, and sillage metrics) is deeply structured, allowing dynamic visual rendering of scent pyramids.

## 🚀 Tech Stack

- **Frontend Library:** React 18
- **Build Tool:** Vite
- **Routing:** React Router v6
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Styling:** Vanilla CSS3 (Custom Properties & Variables)
- **Deployment:** Netlify CI/CD

## 📦 Installation & Setup

To run Sillage locally, follow these steps:

1. **Clone the repository**
   ```bash
   git clone https://github.com/scoprin/perfume-explorer.git
   cd perfume-explorer
   ```

2. **Install Dependencies**
   ```bash
   npm install
   ```

3. **Start the Development Server**
   ```bash
   npm run dev
   ```

4. **Build for Production**
   ```bash
   npm run build
   ```

## 🎨 Design Philosophy

The UI/UX was constructed with luxury aesthetics in mind:
- **Typography:** *Cinzel* (Header) provides a classic, authoritative luxury feel, while *Montserrat* (Body) ensures modern, ultra-clean readability.
- **Color Palette:** A highly refined mix of deep obsidian blacks, marble whites, and muted gold accents to simulate a high-end boutique experience.
- **Micro-Interactions:** Subtle scale and 3D rotational physics on hover states make the application feel tactile and alive.
