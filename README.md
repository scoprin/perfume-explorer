# Perfume Explorer

A clean, beautiful, minimalist dark-mode single-page application for exploring high-end fragrances.

## Features
- **Searchable Database**: Filter by name, brand, notes, or accords.
- **Minimalist Aesthetic**: Dark charcoal background with warm amber and gold accents.
- **Curated Data**: Pulls from FragDB open-source samples.
- **Netlify Ready**: Pre-configured for one-click deployment.
